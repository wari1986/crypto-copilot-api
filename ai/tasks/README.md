# Task Briefs

Use `ai/tasks/*.md` for feature- or initiative-specific briefs that need to persist across sessions.

## How To Use

1. Create or update the active task brief before implementation when work is uncertain, multi-step, or spans multiple sessions.
2. Keep each brief compact, factual, and decision-oriented.
3. Link relevant issues, docs, contracts, or runbooks inside the brief.
4. Update the brief only when scope, approach, or acceptance criteria materially change.

## Naming

- Prefer durable, feature-oriented names such as `market-context-endpoint.md`.
- Prefix with a date only when it helps disambiguate concurrent work.
